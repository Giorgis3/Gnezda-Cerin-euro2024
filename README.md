# 🧠 Adam Gnezda Čerin's Euro 2024 Performance Analysis

## 📊 Project Overview

This project analyzes the performances of **Adam Gnezda Čerin** during **Euro 2024**, focusing on:

- His role in Slovenia’s passing networks  
- Key metrics like danger passes, interceptions, and pass accuracy  
- A data-driven discussion on whether his wage demands at Panathinaikos are justified  

> The analysis is built on top of **StatsBomb open data** and visualization tools from the **Soccermatics Pro course** and **[mplsoccer](https://github.com/andrewRowlinson/mplsoccer)**.

---

## 🧩 Key Features

- Visual passing networks for all four Slovenia matches at Euro 2024  
- Dot plots comparing Čerin to teammates and other players  
- Fully reproducible code to generate the visuals used in the Medium article
